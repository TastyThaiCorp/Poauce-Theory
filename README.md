# Poauce Theory

**Poauce** (pause.) **Theory** — *Pop goes the sauce. Flavors that make you double take.*

Spherified sauced boba beads: sweet, savory, salty, umami. Agar-based (halal,
gelatin-free, pork-free), cold-oil spherification, standardized for commercial
batches. A separate company from Tasty Thai operations.
