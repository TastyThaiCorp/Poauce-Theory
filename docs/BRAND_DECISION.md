## Why not "Sauced"

"Sauced" was the working name, but the risk stack killed it:
- Live pending USPTO applications for SAUCED (serials 98853827 / 98853819, filed Nov 2024, Pur Vin Holdings, tied to Sauced Wine Bar). USPTO TSDR API now requires an API key (since Oct 2, 2026), so status was confirmed via the application's public record rather than a live API pull.
- Operating Sauced Potstickers restaurant (common-law use in food).
- "Sauced" is arguably descriptive of sauced beads, which invites a USPTO descriptiveness refusal even without the conflicts.
- trysauced.com is already registered.

"Saucepop" keeps the entire concept (sauce + pop) while being coined, ownable, and trademark-friendly.

## Trademark screen (informal, web-search based, 2026-10-05)

| Candidate | Result |
|---|---|
| SAUCEPOP | No conflicting food brand or trademark found. Clean. |
| BEADHAUS | Only conflict is Beadhaus Creations, a Hong Kong jewelry business (different class, no food use). Viable backup. |
| POPD | Crowded: POP'D KERNS (live USPTO, corn snacks), Skittles Pop'd (Mars), Fresh Popd Snack Company, Unibic Pop'd. Dropped. |

This is an informal screen, not a formal clearance search. Before filing a federal trademark application, run a proper attorney clearance search.
